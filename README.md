# 《归舟 · 1955》—— 香烟纸上的万里归途

> 单页沉浸式主题介绍站 · 沉浸式红色剧本杀 · 浙江大学校史主题

1955 年，被软禁五年的钱学森，把一封求援信写在一小片香烟纸上送出封锁线。
信要跨过大洋，经比利时、上海、北京，才能成为日内瓦谈判桌上的铁证——
而美方的线人，已经循着墨迹的味道潜了进来。

七位玩家分处这条万里邮路的七个节点，其中最重的一个节点在求是园：
一位老校长要为这封信鉴定笔迹、打通上报的每一级关口。

**排万难、冒百死，以求真知。**

## 响应式

首屏四档版式，区间互斥：

| 区间 | 版式 |
|---|---|
| ≥1501 宽 | 堆叠居中（按屏高分档收紧留白与字号） |
| 861—1500 宽 且 高 ≤820 | **左右分栏**（文案在左，香烟纸在右） |
| 621—860 宽 且 高 ≤700 | 分栏（窄窗/分屏） |
| ≤860 / ≤620 宽 | 手机与窄窗单列 |

关键约定：**只有分栏档位会写 `.hero-inner` 的 transform**，宽屏堆叠档位一律不写缩放，
只用留白与 `clamp(...,vw,...)` 字号控制——避免矮屏缩放规则反向压住分栏版式。

实测覆盖 1600×1000、1440×860、1388×755（高 DPI 外接屏）、1082×603、842×603、518×803
等视口，均无横向溢出、滚动提示在首屏折内。

### 以后怎么更新

**方式一 · 网页上传（最省事）**
在 GitHub 仓库页点 `Add file → Upload files`，把改好的文件拖进去即可，
Pages 会自动重新构建，一两分钟后生效。

**方式二 · 本机 git push**

```powershell
cd "D:\Deepseek workplace\coding\guizhou-1955"
git add -A
git commit -m "更新"
git push
```

> 注意：这台机器上到 `github.com:443` 的 TCP 连接被网络策略挡住
> （`api.github.com` 可达），所以 `git push` 会超时。换一台能连 GitHub 的机器，
> 或在网页上更新。

**方式三 · 走 API 直传（不需要 git push）**

本目录已有一键脚本，用 GitHub 令牌经 `api.github.com` 建 commit：

```powershell
$env:GH_TOKEN = "你的令牌"   # 需要 repo 作用域
node _verify\deploy-api.js --repo guizhou1955_1 --user insoucism --pages
```

脚本幂等：仓库已存在则复用，按内容重建 tree 并快进 `main`。
令牌只从环境变量读，不写入任何文件。
