# 渲染取证工具（过程性代码）

这套脚本是开发「归舟·1955」单页介绍页时用来做**真实渲染取证**的，不属于页面运行的一部分。
页面本体是自包含的（`index.html` + `style.css` + `main.js`），删掉本目录不影响使用。

## 为什么需要它们

版式几何与悬停展开态，光看代码看不出对错，必须让真实浏览器跑一遍并截图核对。

## 用法

需要可访问命名管道的权限（无头 Edge 的 mojo IPC；受限沙箱会以
`platform_channel.cc Check failed: 拒绝访问` 失败）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\_verify\run.ps1
```

产物统一落在 `_verify/out/`（12 张分区图 + 2 张整页长图），该目录可随时清空重建。

> 注意：`run.ps1` 必须保存为 **UTF-8 带 BOM**。Windows PowerShell 5.1 会按 ANSI
> 解码无 BOM 的 `.ps1`，中文注释会破坏字符串字面量并报 `Unexpected token '}'`。

## 四个脚本

| 脚本 | 用途 |
|---|---|
| `mkpage.js` | 生成取证副本：内联 CSS/JS、可选分区隔离、注入装订脚本与探针 |
| `mksettled.js` | 生成「动画终态」副本：关掉全部 `transition/animation`，用于核对垂直节奏 |
| `run.ps1` | 批量截图 12 个交互终态 + 2 张整页长图 |
| `shot-hero.ps1` | 首屏终态截图（7 种视口），专用于核对各断点的首屏折内与留白 |
| `setup-*.js` | 各场景的装订脚本（切 Tab、置开卡片、量取几何） |
| `logic-test.js` | 用最小 DOM 桩在 Node 里跑 `main.js`，快速定位渲染步骤的失败点 |

## 无头取证的两个坑（已在本套工具里规避）

1. **`file://` 下外链资源不解析**
   → 无头 Edge 既不加载 `<link rel=stylesheet>` 也不加载 `<script src>`，
   直接截图会拍到完全未样式化、内容为空壳的页面。`mkpage.js` 因此把 CSS 与 JS 全部内联。

2. **`--virtual-time-budget` 不推进 CSS 过渡，也不保证滚动合成**
   → `scrollIntoView` 常赶不上合成帧，截到的是旧画面；`max-height:0 → 400px`
   这类过渡在探针量取时永远停在起始值。
   解法：分区截图改用 **CSS 隔离**（`.section{display:none}` + 目标 section `display:block`），
   探针副本关掉全部 `transition/animation`，让展开态直接落到终态。

## 实测结论（记录备查）

- 渲染数量：时间轴 **17/17** 节点（史实 15 + 剧本艺术演绎 2）、
  角色卡 **9/9**（含反派 1）、结局 Tab **4/4** 面板且默认仅 1 个可见
- 悬停展开：时间轴气泡 `max-height` 落定 **420px**（实测高 117px 桌面 / 196px 手机）；
  角色梗概落定 **400px**（实测 201px / 150px）
- 反派遮罩：未触发时 `.role-name` 的 `filter` = `blur(4.5px)`，触发后解除
- 首屏折内：在 1600×1000 / 1440×860 / 1366×768 / 1280×720 / 1152×700 / 1024×640 /
  756×1000 / 520×900 八种视口下，slogan 与滚动提示均在首屏之内
- 横向溢出：上述视口 `documentElement.scrollWidth === clientWidth`，无横向滚动
- 系统已装 `NotoSerifSC-VF.ttf` / `NotoSansSC-VF.ttf`，标题衬线字体无需外链即可渲染

## 靠这套工具查出并已修掉的问题

1. **动态生成的 `.reveal` 永远不会显示** —— `initReveal()` 在 `renderTimeline()` /
   `renderRoles()` 之前执行，`IntersectionObserver` 观察不到后插入的节点。
   修法：把 `initReveal()` 挪到所有动态渲染之后，并补 `MutationObserver` 兜底。
2. **悬停展开全部为 0 高** —— 移动端 `@media (max-width:860px)` 里
   `.nav-links{max-height:0}` 会沿后代逐级收紧，把时间轴气泡与角色梗概
   （它们是 `<main>` 的后代）一起算成 0。
   修法：导航展开改用 `grid-template-rows:0fr → 1fr`，不再用 `max-height`。
3. **首屏内容溢出折线** —— 原本 1042px 高塞进 903px 视口，slogan 与滚动提示被裁。
   修法：加矮屏分级（`scale(.92)` / `scale(.78)`，用整体缩放代替继续缩字号），
   并把滚动提示从绝对定位改为文档流内，使内容与留白自然收口。
4. **纸张褶皱遮住信文** —— 折痕光带正好压在正文上，正文发灰。
   修法：折痕改为贴边弱带 + 对角浅折痕，并把正文 `color` 加深、补 `text-shadow`。
5. **核心亮点四张卡排成 3+1** —— `minmax(280px,1fr)` 在 1120px 容器里只放得下 3 列。
   修法：改 `minmax(238px,1fr)`，四卡一行。
6. **手机端 Hero 高达 950px** —— 加手机专属纵向节奏压缩后回到折内。
7. **矮宽屏首屏「不适配」**（用户实测约 1082×590 视口反馈）——
   上下文堆叠到 1042px 塞进 903px 视口，中间空出一条、底部台灯桌面吃掉半屏。
   修法：新增**矮宽屏左右分栏版式**（861—1279 宽且高 ≤740：文案在左、香烟纸在右，
   分栏内整体 `scale(1.1)` 填满屏高），并把场景层压到 11% 高、隐藏桌面散纸。
8. **分栏版式把香烟纸顶出视口** —— 右栏宽度写成固定 px，整体 `scale` 后越界。
   修法：右栏宽度改为 `min(100%, 322px)` 跟列走，缩放时同步收窄。
9. **断点规则互相覆盖** —— 中屏高档位的 `font-size` 被后出现的分栏档位抹掉，
   且滚动提示在 842×603 这类窄窗里溢出 268px。
   修法：三档版式改为互斥区间（≥1280 堆叠 / 861—1279 且高≤740 分栏 / ≤860 手机），
   矮屏分级的最小宽度从 861 放宽到 620，让窄窗也能吃到压缩。
10. **高 DPI 屏首屏"还是很小"**（用户二次反馈，实机截图 2777×1510 物理像素 ÷ 200%
    = 1388×755 CSS 像素）——真凶是**级联里后出现的矮屏规则反向压住了分栏版式**：
   `@media (max-height:770px)` 里遗留的 `scale(.78)` 排在分栏规则之后，
   把已经生效的两栏 `display:grid` 整块缩到 78%，于是"结构对了、字却很小"。
   另外 `max-width:...ch` 会随字号变化，把文案列从 565px 压到 368px。
   修法（`rewrite-responsive.js` 整体重写第 19 节）：
   - 四档版式改成互斥区间，**只有分栏档位会写 `.hero-inner` 的 transform**，
     宽屏堆叠档位一律不写缩放，改用留白与字号（`clamp(...,vw,...)`）控制；
   - 两列宽度改用 px/vw，不用 `ch` 与 `fr`；
   - 新增窄窗+矮屏档位（621—860 宽且高 ≤700），覆盖 842×603 这类小笔记本与分屏窗口。
11. **取证工具自身的两个坑**（导致一度误判）
   - 用 PowerShell `-replace` 注入脚本时，替换串里的 `$&`、`$'` 会被当成替换变量，
     把页面 HTML 改烂（`</span>` 直接漏进正文）。→ 注入一律交给 Node，且用函数式替换。
   - 无头 Edge 偶尔会复用上一帧的渲染结果（换文件名、加 `?v=` 查询、换 user-data-dir
     都可能拿到同一 sha256）。→ 判断版式优先看 DOM 实测值，截图只作辅证；
     需要确证时用 `--overlay` 把几何值画进页面一起拍。
